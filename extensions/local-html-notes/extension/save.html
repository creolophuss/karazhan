批注留在文件里。

高亮、评论和查看脚本一起写入原 HTML。本机助手保存后退出，无模型，无常驻服务。

一次安装，首次保存也不用选文件

macOS Edge 需要 Node.js 24 或更高版本。在 repo 的 extensions/local-html-notes/ 目录执行：

node native/install.mjs --extension-id <扩展 ID>

安装后，在 edge://extensions 重新加载扩展，再刷新报告页。点击「保存」即可直接覆盖当前 HTML，不需要选择原文件。

助手只接受本扩展的保存请求。原文件被外部修改或系统拒绝写入时会停止保存，不下载副本。扩展目录或 Node.js 路径变化后，重新安装助手。

保存到原文件

打开本地 HTML 后，点击页面右上角的「保存」。

首次保存需要选择原 HTML，并允许写入。

首次选择原文件后会记住授权。以后点击报告页的「保存」会直接写回，不切换到本页；关闭本页后也可复用。权限失效时只需点击确认授权。请选原文件；同名副本不能通过浏览器路径自动区分。

使用方法

  1. 在 edge://extensions 开启开发人员模式，加载本扩展目录。
  2. 进入扩展详情，开启「允许访问文件 URL」，再刷新本地 HTML。
  3. 选中文字，点击颜色高亮；双击高亮打开评论对话，输入后点击「添加回复」。
  4. 点击高亮可以改色、删除。点击评论角标查看历史，可编辑、删除自己的消息。
  5. 按上面的命令安装本机助手。点击「保存」直接覆盖原文件，首次也不选择文件，不切换页面。
  6. 按 Ctrl+S 或 macOS 的 Cmd+S 保存。每 30 秒自动保存已添加且有改动的批注；失败后暂停，手动成功保存或刷新后恢复。
  7. 将已保存的 HTML 交给 LLM，按项目使用说明中的提示词写回回复。完成后刷新报告页，可继续回复并保存。LLM 消息在界面中只读。

支持 UTF-8 HTML 和脚本生成的正文。保存后，原报告脚本继续运行，批注在正文生成或更新后恢复；其他浏览器不安装扩展也能查看。PDF 和跨报告批注迁移不在本期范围。

写入失败时，不会清除页面中的未保存批注。请保留报告页，并按提示处理。
