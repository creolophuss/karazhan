# 本地 HTML 批注 · Edge 扩展

这是 Karazhan 仓库中的独立组件，不依赖 Karazhan 桌面应用。

无需服务或安装依赖。高亮和评论直接存入原 HTML。扩展只记住文件授权，不在数据库中保存正文和批注。无 `.bak` 或云端。

## 安装

1. 用桌面 Edge 打开 `edge://extensions`。
2. 开启「开发人员模式」，点击「加载解压缩的扩展」。
3. 选择本目录下的 **`extension/`**，即仓库中的 `extensions/local-html-notes/extension/`。
4. 打开该扩展的「详细信息」，开启「允许访问文件 URL」。
5. 打开本地 `.html`；如果页面已经打开，刷新一次。

可先复制 `tests/fixtures/测试 报告.html`，用副本试用。项目不需要启动命令。

更新扩展后，在 `edge://extensions` 点击扩展卡片上的「重新加载」，再刷新报告页。当前版本为 **1.3.0**。

## 批注与保存

- 选中文字，点击浮层中的颜色高亮。点击外部或按 Esc 取消。
- 双击高亮打开评论对话。输入后点击「添加回复」，消息会加入历史，输入框清空。关闭对话后点击页面右上角「保存」。
- 点击评论角标可查看完整对话，悬停可查看消息数量及最后一条摘要。消息按加入顺序显示「我」或「LLM」及时间。
- 你可以编辑、删除自己的消息；编辑后显示「已编辑」。LLM 消息在界面中只读。删除消息保留高亮；删除高亮同时删除整段对话。
- 首次点击页面右上角「保存」，在扩展保存页选择当前报告的原 HTML 并授权。请选原文件，不要选同名副本。
- 成功后自动返回报告，右上角显示「已保存」。之后再点「保存」会复用文件授权，通常不需要重新选择文件。
- 关闭保存页、刷新报告或重启 Edge 后，扩展仍记住文件。权限失效时，在保存页点击「确认授权并保存」即可，通常不用重新找目录。
- 浏览器会记住此选择器上次使用的目录。原文件被移动、删除，或扩展数据被清除后，需要重新选择。
- 如需移除记忆，切回保存页，点击「忘记此文件」。这只移除扩展中的文件关联；浏览器自身的文件权限需在 Edge 中管理。
- 旧版本已打开的保存页不会自动迁移授权。更新至 1.3.0 后重新选一次，成功保存后开始记住授权。
- 保存后刷新或重开可继续编辑。另一个浏览器没有扩展，也能查看已保存的高亮和评论。
- 支持脚本生成或更新的正文。页面重新渲染后，会按选中文字及前后文恢复批注；暂时找不到或不能唯一定位时显示待定位数量，保留批注数据。

## 与 LLM 来回讨论

1. 添加问题后，保存 HTML，等到显示「已保存」。
2. 将该 HTML 交给能直接编辑文件的 LLM，并附上下方提示词。LLM 需将回复写回你下一步打开的同一个 HTML。
3. LLM 完成写回后，手动刷新 Edge 中的报告页，点击评论角标查看回复。
4. 在同一对话里继续输入并点击「添加回复」，关闭对话后保存。再次交给 LLM 即可继续讨论。

工具不调用模型 API，也不配置模型或密钥。只有聊天能力的 LLM 可以给出文字答复，但不能自动将回复写回文件。

可复制的提示词（将文件路径替换为实际路径）：

```text
请直接编辑这个 HTML：<文件路径>，回复其中待回答的评论对话。
先阅读文件尾部 LOCAL_HTML_NOTES_LLM_PROTOCOL_V2 注释，遵守该协议。
在 script#notes-data 的 version: 2 数据中，逐条检查 notes：
- 只回复 messages 非空且最后一条 role 为 user 的对话；其余跳过。
- 结合 selector.exact、前后文、报告内容和完整消息历史，回答用户。
- 只向对应 messages 末尾追加一条消息：id 为新 UUID，role 为 assistant，
  content 为纯文本回复，createdAt 为当前 UTC ISO 8601 时间；同步更新 note.updatedAt。
- 保留已有消息、id、锚点及其他字段，不编辑或删除历史。
- 仅替换 script#notes-data 的 JSON 文本；其余 HTML 字节保持原样，
  包括原文、原报告脚本、批注查看脚本及样式。JSON 中的 < 写成 \u003c，避免结束 script。
- 写回同一文件，不生成备份或旁路文件；完成后告知我刷新报告页查看。
```

旧版文件会在打开时将单段评论转为一条「我」的消息；空评论保持空对话。下次保存统一写入 `notes-data` version 2 的 `notes[].messages`，不再写 `comment` 字段。每条消息含 `id`、`role`、`content`、`createdAt`，编辑自己的消息时另写 `editedAt`。每个高亮仍保留原 ID 和定位锚点。

LLM 写回后，旧页面不能覆盖新文件；保存时会提示外部修改。请先保存你的问题，再交给 LLM；看到外部修改提示时，先复制尚未保存的文字，再刷新页面并重新添加。

## 限制和失败处理

- 支持 UTF-8 HTML。没有 PDF、下划线、删除线、跨报告批注迁移、自动保存或备份。
- 不支持 iframe、Shadow DOM 或 canvas 文字。原 HTML 的内容安全策略阻止批注脚本或样式时会提示，不修改其策略。
- 原报告的脚本和资源引用会保留。脚本生成的正文需由原报告脚本在重开后继续生成；动态测试文件为 `tests/fixtures/脚本 报告.html`。
- 重叠高亮不创建；请操作已有高亮。报告的外部图片、字体和脚本仍保留原引用。
- 原文件被外部修改、选错文件、拒绝权限或写入失败时，停止覆盖并显示原因。保留报告页，未保存批注仍在内存中。
- IndexedDB 仅存文件授权句柄，按原文件 URL 区分，不存正文、批注或历史副本。存储不可用时会提示，当前保存仍可完成；保存页打开期间可继续复用授权。浏览器是否长期保留写权限由 Edge 决定。
- 浏览器不提供所选文件的完整路径。工具检查文件名及内容，但无法区分字节相同的同名副本。
- 扩展保存页也包含一页使用说明。点击扩展图标可打开它。

## 开发验证

开发需要 Node.js 24 或更高版本。扩展运行时不需要 Node.js 或 npm 依赖。

从 Karazhan 仓库根目录执行：

```sh
cd extensions/local-html-notes
npm ci
npm test
```

测试只写入本组件的 `artifacts/validation/`，该目录不入库。依赖目录 `node_modules/` 也不入库。

自动测试使用 jsdom 模拟页面、扩展消息、文件选择、写权限和 IndexedDB。写入测试只使用测试副本。模拟测试不能证明 Edge 原生文件授权、句柄序列化、重启后的权限或其他浏览器的显示行为。

原生浏览器验收需使用测试副本。重新加载扩展后，依次验证选区、高亮、评论、首次保存授权、关闭保存页、刷新后继续回复和再次保存。重启 Edge 后检查授权复用。再检查 LLM 写回后的对话，并在另一个浏览器查看保存结果。
