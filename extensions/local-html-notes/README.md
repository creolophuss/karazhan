# 本地 HTML 批注 · Edge 扩展

这是 Karazhan 仓库中的独立组件，不依赖 Karazhan 桌面应用。

高亮和评论直接存入原 HTML。首次保存也不需要选择文件。macOS Edge 通过一次性安装的本机助手写入；助手按需启动，保存后退出，无 Agent、模型或常驻服务。无 `.bak` 或云端。

## 安装

1. 用桌面 Edge 打开 `edge://extensions`。
2. 开启「开发人员模式」，点击「加载解压缩的扩展」。
3. 选择本目录下的 **`extension/`**，即仓库中的 `extensions/local-html-notes/extension/`。
4. 打开该扩展的「详细信息」，开启「允许访问文件 URL」。
5. 打开本地 `.html`；如果页面已经打开，刷新一次。

可先复制 `tests/fixtures/测试 报告.html`，用副本试用。项目不需要启动命令。

更新扩展后，在 `edge://extensions` 点击扩展卡片上的「重新加载」，再刷新报告页。当前版本为 **1.6.0**。

## 一次性安装本机助手

此版本支持 macOS Edge。需要 Node.js 24 或更高版本；不需要安装 npm 依赖，也不依赖 Karazhan App。

1. 按上面的步骤加载本 repo 的 `extension/`。
2. 在 `edge://extensions` 复制「本地 HTML 批注」的 32 位 ID。点击扩展图标打开的说明页也会显示 ID 和安装命令。
3. 进入本组件目录，执行以下命令，将占位符换成实际 ID：

```sh
cd extensions/local-html-notes
node native/install.mjs --extension-id <32位扩展ID>
```

4. 回到 `edge://extensions` 重新加载扩展。如浏览器提示新增权限，确认本机通信权限，再刷新报告页。
5. 添加批注并点击「保存」。第一次就会覆盖当前 HTML，不出现文件选择器。

安装命令只登记当前用户的 Edge，不需要管理员权限。它创建：

- `~/Library/Application Support/Karazhan Local HTML Notes/`：助手、启动脚本和扩展白名单。
- `~/Library/Application Support/Microsoft Edge/NativeMessagingHosts/com.karazhan.local_html_notes.json`：Edge 的助手登记。

助手只允许安装时指定的扩展 ID。浏览器负责启动程序；程序处理一个保存请求后退出。它不打开网络端口，不调用模型，也不保存正文或批注数据库。安装时记录 Node.js 的绝对路径；移动或删除 Node.js 后，重新运行安装命令。更新助手代码后也运行同一命令。使用其他浏览器或 Edge 渠道的安装不在本版本范围内。

助手无法连接时，报告页会提示安装或更新，不会自动打开文件选择器或下载副本。安装方法依据 [Edge Native Messaging 文档](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/native-messaging)。

## 批注与保存

- 选中文字，点击浮层中的颜色高亮。点击外部或按 Esc 取消。
- 双击高亮打开评论对话。输入后点击「添加回复」，消息会加入历史，输入框清空。关闭对话后点击页面右上角「保存」。
- 点击评论角标可查看完整对话，悬停可查看消息数量及最后一条摘要。消息按加入顺序显示「我」或「LLM」及时间。
- 你可以编辑、删除自己的消息；编辑后显示「已编辑」。LLM 消息在界面中只读。删除消息保留高亮；删除高亮同时删除整段对话。
- 按 Ctrl+S 保存；macOS 也支持 Cmd+S。快捷键保存批注，不打开浏览器的另存为窗口。
- 每 30 秒检查一次；批注有未保存修改时自动覆盖原文件。没有改动或正在保存时跳过。浏览器可能延迟后台标签页的定时器。
- 仅保存已添加的回复；输入框中尚未点击「添加回复」的草稿不会自动提交。保存失败后暂停自动保存并提示；手动保存成功或刷新后恢复。旧浏览器需要文件授权时，定时器只提示，不自动打开授权页。
- 安装助手后，点击「保存」直接覆盖地址栏对应的原 HTML。成功时显示「已保存」，报告页保持打开；保存期间按钮暂时禁用。
- 刷新报告或重启 Edge 后仍可直接保存，不需要为每个文件单独授权。只支持当前用户有系统写权限的现有普通 `.html` 文件；不创建缺失文件，不覆盖符号链接或硬链接。
- 原文件被 LLM 或其他程序修改后，停止覆盖并提示。请先复制尚未保存的文字，再刷新原文件并重新添加。
- 保存后刷新或重开可继续编辑。另一个浏览器没有扩展，也能查看已保存的高亮和评论。
- 支持脚本生成或更新的正文。页面重新渲染后，会按选中文字及前后文恢复批注；暂时找不到或不能唯一定位时显示待定位数量，保留批注数据。
- 批注格式保持 version 2，已有 HTML 和对话不需要迁移。1.3.0/1.4.0 存下的文件授权不再用于本机助手保存；缺少 Native Messaging API 的旧环境仍保留原文件授权流程。

## 与 LLM 来回讨论

1. 添加问题后，保存 HTML，等到显示「已保存」。
2. 将该 HTML 交给能直接编辑文件的 LLM，并附上下方提示词。LLM 需将回复写回你下一步打开的同一个 HTML。
3. LLM 完成写回后，手动刷新 Edge 中的报告页，点击评论角标查看回复。
4. 在同一对话里继续输入并点击「添加回复」，关闭对话后保存。再次交给 LLM 即可继续讨论。

工具不调用模型 API，也不配置模型或密钥。只有聊天能力的 LLM 可以给出文字答复，但不能自动将回复写回文件。

可复制的提示词（将文件路径替换为实际路径）：

```text
请直接编辑这个 HTML：<文件路径>，回复其中待回答的评论对话。
先阅读文件尾部 LOCAL_HTML_NOTES_LLM_PROTOCOL_V2 注释，遵守该协议。
在 script#notes-data 的 version: 2 数据中，逐条检查 notes：
- 只回复 messages 非空且最后一条 role 为 user 的对话；其余跳过。
- 结合 selector.exact、前后文、报告内容和完整消息历史，回答用户。
- 只向对应 messages 末尾追加一条消息：id 为新 UUID，role 为 assistant，
  content 为纯文本回复，createdAt 为当前 UTC ISO 8601 时间；同步更新 note.updatedAt。
- 保留已有消息、id、锚点及其他字段，不编辑或删除历史。
- 仅替换 script#notes-data 的 JSON 文本；其余 HTML 字节保持原样，
  包括原文、原报告脚本、批注查看脚本及样式。JSON 中的 < 写成 \u003c，避免结束 script。
- 写回同一文件，不生成备份或旁路文件；完成后告知我刷新报告页查看。
```

旧版文件会在打开时将单段评论转为一条「我」的消息；空评论保持空对话。下次保存统一写入 `notes-data` version 2 的 `notes[].messages`，不再写 `comment` 字段。每条消息含 `id`、`role`、`content`、`createdAt`，编辑自己的消息时另写 `editedAt`。每个高亮仍保留原 ID 和定位锚点。

LLM 写回后，旧页面不能覆盖新文件；保存时会提示外部修改。请先保存你的问题，再交给 LLM；看到外部修改提示时，先复制尚未保存的文字，再刷新页面并重新添加。

## 限制和失败处理

- 支持 UTF-8 HTML。没有 PDF、下划线、删除线、跨报告批注迁移或备份。
- 不支持 iframe、Shadow DOM 或 canvas 文字。原 HTML 的内容安全策略阻止批注脚本或样式时会提示，不修改其策略。
- 原报告的脚本和资源引用会保留。脚本生成的正文需由原报告脚本在重开后继续生成；动态测试文件为 `tests/fixtures/脚本 报告.html`。
- 重叠高亮不创建；请操作已有高亮。报告的外部图片、字体和脚本仍保留原引用。
- 原文件被外部修改、系统拒绝写入或磁盘写入失败时，停止覆盖并显示原因。保留报告页，未保存批注仍在内存中。保存过程中「保存」按钮暂时禁用，防止重复提交。
- 写入先检查原内容摘要，再在同一目录创建临时文件、保留文件模式并替换原文件。正常结束时删除临时文件和锁；不保留 `.bak`。助手被强行终止时，可能留下 `.local-html-notes.lock` 或 `.tmp`，后续保存会停下。先确认没有保存正在进行，再检查并移除该文件的临时文件；不要删除原 HTML。
- 并发检查覆盖同一助手的写入及提交前的外部变化。它不能锁住所有外部编辑器；请不要同时让 LLM 和浏览器写同一报告。
- IndexedDB 中可能保留旧版文件授权，不含正文或批注。本机助手流程不读取这些授权。
- 扩展保存页也包含一页使用说明。点击扩展图标可打开它。

## 开发验证

开发需要 Node.js 24 或更高版本。扩展运行时不需要 Node.js 或 npm 依赖。

从 Karazhan 仓库根目录执行：

```sh
cd extensions/local-html-notes
npm ci
npm test
```

测试只写入本组件的 `artifacts/validation/`，该目录不入库。依赖目录 `node_modules/` 也不入库。

自动测试使用 jsdom 模拟页面和扩展消息，并启动真实本机进程验证消息分帧、首次覆盖、安装启动脚本、冲突和失败保护。写入测试只使用测试副本。旧版文件授权测试仍模拟选择器、写权限和 IndexedDB。模拟测试不能代替 Edge 原生扩展加载和界面验收。

原生浏览器验收需使用测试副本。加载扩展、安装助手并刷新报告后，依次检查选区、高亮、评论和首次保存；确认没有文件选择器，报告页保持打开。再检查刷新/重启后的保存、LLM 外部写回的冲突提示，以及其他浏览器的离线查看。只验证文件摘要和模拟进程不能代替实际浏览器保存。
