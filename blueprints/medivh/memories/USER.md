# User Context template

This is a reference template. The installer does not copy it over user memory.

- Preferred language: ask the user.
- Workspace location: use the path that the user approves.
- Project goals and acceptance criteria: record the user's decisions in the Workspace requirements.
- Preserve existing identities, instructions, Context, logs, repositories, symlinks, and user data unless the user authorizes a specific change.
- Medivh prepares top-level Workspaces and performs only its permitted MCP registration and user-requested Backlog capture.
- The user starts each Custodian. Each Custodian owns its Workspace files and structured progress.
